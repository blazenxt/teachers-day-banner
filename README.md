# Happy Teacher's Day Banner

Black & gold Teacher's Day celebration banner page for coaching.

## Local preview

```bash
cd teachers-day-banner
npx serve . -l 3000
```

## Deploy to Vercel

### Option A — Vercel CLI (fastest)

```bash
npm i -g vercel
cd teachers-day-banner
vercel login
vercel
```

Production deploy:

```bash
vercel --prod
```

### Option B — GitHub + Vercel Dashboard

1. Create a GitHub repo and push this folder
2. Go to [vercel.com/new](https://vercel.com/new)
3. Import the repo
4. Click **Deploy** (no build settings needed — static site)

Live link mil jayega jaise: `https://teachers-day-banner.vercel.app`
